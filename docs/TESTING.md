# Snapix v0.6.3 统一测试清单

> 安装 `src-tauri\target\release\bundle\nsis\Snapix_0.6.3_x64-setup.exe` 后逐项勾选。
> 涉及快捷键的项目，先到「设置 → 快捷键」配好再测。

## 1. 基础截图链路

- [ ] `Ctrl+Shift+A` 唤起遮罩，屏幕冻结无闪烁
- [ ] 拖拽出选区，尺寸/坐标标签正确（物理像素）
- [ ] 悬停窗口自动高亮吸附，单击选中该窗口
- [ ] `Tab` 切换到「元素吸附」，可选中按钮/输入框等控件，再按 `Tab` 切回
- [ ] 选区可拖动、8 手柄缩放、方向键微调（`Ctrl+方向键` 调大小、`Shift` 步进 10px）
- [ ] **Shift+拖拽 = 正方形选区；Shift+拖角点 = 正方形缩放**（新）
- [ ] 放大镜跟随，像素坐标与色值实时更新
- [ ] `C` 复制 HEX 色值；**`Shift+C` 复制 `rgb(...)` 色值**（新）
- [ ] `Enter` / 双击 = 复制并关闭；`Ctrl+C/S/T/E` = 复制/保存/贴图/标注
- [ ] 右键：有选区时回退选区，无选区时退出；`Esc` 直接退出
- [ ] 多显示器：每块屏都有遮罩，鼠标移到哪块屏即可在该屏选区（若有多屏）

## 2. 即拍与延时

- [ ] **全屏即拍**（设置快捷键后按下）：瞬间复制整屏到剪贴板，**弹系统通知**（新）
- [ ] **窗口即拍**（设置快捷键后按下）：截取当前活动窗口，通知里显示窗口标题（新）
- [ ] 「直接保存」模式下，全屏/窗口即拍同时静默存盘，通知带文件名
- [ ] 托盘「全屏即拍」、主页「全屏」按钮可用
- [ ] 延时截图 3s/5s/10s（托盘 + 主页）
- [ ] 重复上次区域：预选上次选区，可再调整

## 3. OCR 与二维码

- [ ] 选区后点「OCR / 二维码识别」：中英文文字识别正确
- [ ] **选区内有二维码时，结果面板顶部出现二维码内容条，可单独复制**（新）
- [ ] 纯二维码（无文字）也能出结果；「复制文字」按钮复制 OCR 文本

## 4. 滚动长截图

- [ ] 选区后点「滚动长截图」：自动滚动拼接，控制条显示进度
- [ ] 触底自动完成 / `Enter` 手动完成 → 长图进入编辑器
- [ ] `Esc` 取消不产出
- [ ] 带固定表头的页面（如表格）拼接无重复表头

## 5. GIF 录屏（新）

- [ ] 选区后点「录制 GIF」：遮罩收起，出现红色描边框 + 控制条
- [ ] 控制条实时显示时长与帧数；录制区内容变化被记录
- [ ] `Enter` / 停止按钮：**弹「GIF 已保存」通知并在资源管理器定位文件**
- [ ] 成品 GIF 可正常播放，帧率约 10fps，循环播放
- [ ] `Esc` / 取消按钮：不产出文件
- [ ] 大选区（>1280px 宽）录制后成品被等比缩小
- [ ] 录制中按截图快捷键无响应（防套娃），录完恢复

## 6. 标注编辑器

工具（左侧栏，括号内为单键快捷键）：

- [ ] 选择 (V)：点选、拖动、变换图形
- [ ] 矩形 (R) / 椭圆 (O)：**「描边 / 填充」切换**（新）；椭圆可用手柄缩放（新）
- [ ] 箭头 (A) / 直线 (L)：端点可拖拽编辑
- [ ] 画笔 (P) / 荧光笔 (H)
- [ ] 文字 (T)：双击再编辑；**可旋转**（新）
- [ ] 步骤序号 (N)：自动递增
- [ ] **Emoji 贴纸 (E)：顶栏选 emoji，点击放置，角点等比缩放、可旋转**（新）
- [ ] **聚光灯 (F)：拖出高亮区，四周压暗；可多个、可拖动缩放**（新）
- [ ] **测量标尺 (D)：拉线显示像素距离，端点可微调**（新）
- [ ] 马赛克 (M) / 模糊 (B)：**选中后顶栏出现强度滑杆**（新）
- [ ] 裁剪 (C)：非破坏式，chip 一键还原
- [ ] **矩形/椭圆/贴纸旋转手柄，45° 自动吸附**（新）

操作与出图：

- [ ] `Ctrl+Z / Ctrl+Y` 撤销重做；`Delete` 删除所选
- [ ] **`Ctrl+滚轮` 缩放画布，`Ctrl+0` 重置，右下角显示缩放比**（新）
- [ ] `Esc`：有选中先取消选中，再按关闭编辑器
- [ ] 「自动打码」：含手机号/邮箱的截图能自动马赛克
- [ ] 「美化」：背景/边距/圆角/投影/比例/水印/窗口边框，导出与预览一致
- [ ] 复制 / 保存出图正确（含标注、裁剪、美化、聚光灯压暗）
- [ ] **Shift+点击复制或保存 = 出图后不关闭编辑器**（新）
- [ ] **「贴图」按钮：标注成图直接钉到屏幕**（新）
- [ ] **`Ctrl+V`：剪贴板图片直接进编辑器开新一轮标注**（新）
- [ ] **聚光灯选中时的虚线框不会出现在导出图里**（新）
