# Snapix

全能 Windows 截图工具 — 截图、标注、贴图、OCR、滚动长截图（纵向 / 横向）、出图美化。基于 **Tauri 2 + React + TypeScript**。

> 设计与开发计划见 [`docs/DESIGN.md`](docs/DESIGN.md) 与 [`docs/PLAN.md`](docs/PLAN.md)。

## 开发 / 打包

```bash
pnpm install
pnpm tauri dev     # 开发调试
pnpm tauri build   # 产出安装包（src-tauri/target/release/bundle/nsis）

pnpm check         # tsc 类型检查 + ESLint
pnpm test          # Vitest（前端纯逻辑）
cd src-tauri && cargo clippy --all-targets && cargo test   # Rust 侧
```

## 发布与自动更新

更新走 GitHub Releases（端点见 `src-tauri/tauri.conf.json → plugins.updater.endpoints`，当前指向 `neview/snapix`，换仓库时改这一处即可）。安装包用 minisign 签名，客户端只接受用对应私钥签出的包。

1. **版本号**：`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 三处保持一致。
2. **签名密钥**：`.tauri-keys/snapix.key`（已加入 `.gitignore`）。**务必备份**——丢失后已安装的客户端将无法校验新包，只能手动重装。
3. **发布**：`git tag v0.6.2 && git push origin v0.6.2`，`.github/workflows/release.yml` 会自动构建 NSIS / MSI、生成 `latest.json` 并挂到 Release。
   仓库 Secrets 需要 `TAURI_SIGNING_PRIVATE_KEY`（私钥文件全文）与 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`（密钥无密码可留空）。
4. **本地出包**（带更新签名）：

   ```powershell
   $env:TAURI_SIGNING_PRIVATE_KEY = Get-Content .tauri-keys/snapix.key -Raw
   pnpm tauri build
   ```

   `createUpdaterArtifacts` 会额外产出 `.nsis.zip` 与 `.sig`；发布到 GitHub 时由 tauri-action 汇总进 `latest.json`。

5. **兼容性**：自动更新从 **0.6.2** 开始生效；0.6.1 及更早版本没有 updater，需要手动安装一次 0.6.2。
6. **代码签名（待接入）**：当前安装包未签名，首次安装可能出现 SmartScreen「未知发布者」。购买 Windows 代码签名证书后，
   在 `bundle.windows` 配置 `certificateThumbprint` / `signCommand` 并在 CI 导入证书即可消除提示；
   自动更新下载的安装器在部分杀软/企业策略下也需要有效签名才能静默运行。

### 快捷键（默认）

- 截图：`Ctrl+Shift+A`（设置中可改，另有全屏即拍/窗口即拍/重复上次/贴图剪贴板/隐藏贴图五个可配键位）。
- 遮罩内：`Enter`/双击完成复制、`Ctrl+C/S/T/E` 复制/保存/贴图/标注、`Ctrl+A` 全屏、`Shift` 拖拽正方形、方向键微调选区（`Ctrl`=调大小、`Shift`=步进 10px）、`C` 复制 HEX / `Shift+C` 复制 RGB、`Tab` 切换窗口/元素吸附、右键回退、`Esc` 取消。
- 编辑器：`V/R/O/A/L/P/H/T/N/E/F/D/M/B/C` 切换工具、`Ctrl+Z/Y` 撤销重做、`Ctrl+C` 复制出图、`Ctrl+S` 保存出图、`Ctrl+V` 标注剪贴板图片、`Ctrl+滚轮` 缩放画布（`Ctrl+0` 重置）、`Delete` 删除所选、`Esc` 取消选中/关闭。
- 贴图窗：滚轮缩放、`Ctrl+滚轮` 透明度、`R` 旋转、`F` 翻转、`0` 重置、`Ctrl+C` 复制、`Ctrl+S` 另存、`Esc`/双击关闭、右键菜单（标注 / 鼠标穿透等）。
- 晾衣绳：吸附在屏幕顶部，图可沿绳拖动（拖动时随速度左右摆、松手阻尼回摆）；悬停出「复制 / 展开 / 删除」，
  右键菜单还有「保存 / 删除」（删除需两次确认）；点击缩略图展开成贴图，展开后的贴图**双击即飞回绳上原位置**；
  托盘可显示/隐藏或清空。
- 关闭主窗口会收进托盘（快捷键仍可用），从托盘菜单退出。
